# Adams Plain-Grade Writing Skill

**Axiom:** If language has been litigated, it is bad language.  
Write the simplest true version that still keeps the exact meaning.

## Goal
Aim for 5th-grade reading level (USA Southeast) whenever you can.  
Use 8th-grade only when a precise idea cannot stay accurate at 5th-grade.  
Never make the meaning fuzzy just to hit a lower grade.

## Grade Targets

**Preferred – 5th grade**
- Average sentence length: 10–14 words
- Everyday concrete words (prefer 1–2 syllables)
- Active voice
- One main idea per sentence
- Concrete examples
- Target: Flesch Reading Ease near 90–100 or Flesch-Kincaid near 5.0

**Fallback – 8th grade**
- Use only when precision needs it
- Sentences may reach 15–18 words
- Still keep words common and concrete
- Explain any technical term right away in plain words

Never go above 8th grade. Never sacrifice Adams clarity to hit a lower grade.

## Adams Rules (never drop these)
- Litigated language is bad language. Do not use it.
- No archaisms, no doublets or triplets, no ambiguity.
- Use the simplest accurate modern English word.
- If you must use a technical term, say it once and explain it right away in plain words.
- Structure the text so the reader never has to guess what you mean.
- Keep the subject, verb, and object close.

## How to Write
1. Find the one most important point.
2. Say it first in the simplest true sentence.
3. Tell why it matters in one short sentence.
4. Add the rest in short bullets or very short paragraphs.
5. Check the grade level. Rewrite until it is 5th-grade or (only if needed) 8th-grade.
6. Read it out loud. It should sound like a clear adult talking to a smart 11-year-old from the Southeast.

## When to Use This Skill
- Patient or client materials
- Public explanations
- Requests for “plain English,” “simple,” “5th grade,” “easy to read,” or “low literacy”
- Any time the audience needs the most accessible clear version

## How It Works with the Main Skill
- Use **adams-smart-brevity** for professional, technical, or internal writing.
- Use **adams-plain-grade** when the audience needs the simplest accurate version.
- Both skills keep the same Adams core: clarity first, no tested language, no ambiguity.

## Self-Check Before You Finish
- [ ] Main point is first and simple
- [ ] Sentences are short
- [ ] Words are everyday words
- [ ] No litigated or traditional formulas
- [ ] No ambiguity
- [ ] Grade is 5th if possible, never higher than 8th
- [ ] A 5th-grader in the Southeast United States could understand it without help
